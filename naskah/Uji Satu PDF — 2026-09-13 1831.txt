Pembahasan
PG1-Laju konduksi kedua logam sama saat tunak $H_P = H_Q \Rightarrow \frac{k_P A (100 - T_s)}{L} = \frac{k_Q A (T_s - 25)}{L}$. Karena $k_P = 2k_Q$, maka $2(100 - T_s) = T_s - 25 \Rightarrow 200 - 2T_s = T_s - 25 \Rightarrow 3T_s = 225 \Rightarrow T_s = 75^{\circ}\text{C}$.
PG2-Angin laut/darat terjadi akibat aliran massa udara panas dan dingin (konveksi). Panas api unggun dirasakan di samping melalui pancaran radiasi elektromagnetik (radiasi). Sendok panas akibat rambatan partikel zat padat tanpa perpindahan massa partikelnya (konduksi).
PG3-Laju konduksi $H = \frac{k A \Delta T}{L}$. Rasio laju adalah $\frac{H_X}{H_Y} = \left(\frac{A_X}{A_Y}\right) \times \left(\frac{L_Y}{L_X}\right) = \left(\frac{2}{3}\right) \times \left(\frac{2}{1}\right) = \frac{4}{3}$.
PG4-Kalor merambat melalui molekul dinding silinder pompa dari bagian dalam ke luar secara kontak langsung tanpa pergeseran medium zat padat, yang merupakan ciri konduksi.
PG5-Daya radiasi $P = e \sigma A T^4$ dengan luas bola $A = 4\pi R^2$. Maka $P \propto R^2 T^4$. Perbandingan daya baru $P' = P \times \left(\frac{R'}{R}\right)^2 \times \left(\frac{T'}{T}\right)^4 = P \times \left(\frac{1}{2}\right)^2 \times (2)^4 = P \times \frac{1}{4} \times 16 = 4P$.
PG6-Dari $G = \frac{F r^2}{m_1 m_2}$, dimensinya adalah $[G] = \frac{[M][L][T]^{-2} [L]^2}{[M]^2} = [M]^{-1}[L]^{3}[T]^{-2}$.
PG7-Suku-suku penjumlahan harus berdimensi sama dengan energi: $[\alpha v^2] = [M][L]^2[T]^{-2} \Rightarrow [\alpha] [L]^2[T]^{-2} = [M][L]^2[T]^{-2} \Rightarrow [\alpha] = [M]$. Suku kedua $[\beta x^2] = [M][L]^2[T]^{-2} \Rightarrow [\beta] [L]^2 = [M][L]^2[T]^{-2} \Rightarrow [\beta] = [M][T]^{-2}$. Maka dimensi rasio $\left[\frac{\alpha}{\beta}\right] = \frac{[M]}{[M][T]^{-2}} = [T]^2$.
PG8-Analisis dimensi periode: $[T]^1 = ([L])^x ([L][T]^{-2})^y = [L]^{x+y} [T]^{-2y}$. Menyamakan pangkat: untuk $[T]$, $1 = -2y \Rightarrow y = -\frac{1}{2}$. Untuk $[L]$, $0 = x + y \Rightarrow x = -y = \frac{1}{2}$.
PG9-Berdasarkan prinsip homogenitas dimensi, suku $\frac{a}{V^2}$ harus memiliki dimensi yang sama dengan tekanan $P$. Dimensi tekanan $[P] = [M][L]^{-1}[T]^{-2}$ dan volume $[V] = [L]^3 \Rightarrow [V^2] = [L]^6$. Maka $[a] = [P] \cdot [V^2] = [M][L]^{-1}[T]^{-2} \cdot [L]^6 = [M][L]^5[T]^{-2}$.
PG10-Dari rumus konduksi $k = \frac{H L}{A \Delta T} = \frac{Q L}{t A \Delta T}$, satuan SI adalah $\frac{\text{J}\cdot\text{m}}{\text{s}\cdot\text{m}^2\cdot\text{K}} = \text{J}\cdot\text{s}^{-1}\cdot\text{m}^{-1}\cdot\text{K}^{-1}$. Dimensi energi $[Q] = [M][L]^2[T]^{-2}$, sehingga $[k] = \frac{[M][L]^2[T]^{-2} [L]}{[T] [L]^2 [\theta]} = [M][L][T]^{-3}[\theta]^{-1}$.
E1-Kesetimbangan termal lempeng sejenis ($k_A = k_B$) mengharuskan laju alir kalor sama: $\frac{k A (120 - T_s)}{L_A} = \frac{k A (T_s - 20)}{L_B} \Rightarrow \frac{120 - T_s}{0{,}04} = \frac{T_s - 20}{0{,}06} \Rightarrow 3(120 - T_s) = 2(T_s - 20) \Rightarrow 360 - 3T_s = 2T_s - 40 \Rightarrow 5T_s = 400 \Rightarrow T_s = 80^{\circ}\text{C}$. Satuan $k$ diturunkan dari $k = \frac{Q L}{t A \Delta T}$ menjadi $\frac{\text{kg}\cdot\text{m}^2\cdot\text{s}^{-2}\cdot\text{m}}{\text{s}\cdot\text{m}^2\cdot\text{K}} = \text{kg}\cdot\text{m}\cdot\text{s}^{-3}\cdot\text{K}^{-1}$. Dimensinya diperoleh $[k] = [M][L][T]^{-3}[\theta]^{-1}$.
E2-Gaya hambat $[F_D] = [M][L][T]^{-2}$ dan massa jenis $[\rho] = \frac{[M]}{[L]^3} = [M][L]^{-3}$. Persamaan dimensi: $[M][L][T]^{-2} = ([M][L]^{-3})^a ([L][T]^{-1})^b ([L]^2)^c = [M]^a [L]^{-3a+b+2c} [T]^{-b}$. Dari massa diperoleh $a = 1$. Dari waktu didapat $-b = -2 \Rightarrow b = 2$. Dari panjang didapat $-3(1) + 2 + 2c = 1 \Rightarrow -1 + 2c = 1 \Rightarrow 2c = 2 \Rightarrow c = 1$.
E3-Dimensi kecepatan $[v] = [L][T]^{-1}$ dan gaya $[F] = [M][L][T]^{-2}$. Persamaan dimensi: $[L][T]^{-1} = ([M][L][T]^{-2})^x [L]^y [M]^z = [M]^{x+z} [L]^{x+y} [T]^{-2x}$. Dari kesamaan pangkat waktu diperoleh $-2x = -1 \Rightarrow x = \frac{1}{2}$. Dari massa diperoleh $x + z = 0 \Rightarrow z = -x = -\frac{1}{2}$. Dari panjang diperoleh $x + y = 1 \Rightarrow \frac{1}{2} + y = 1 \Rightarrow y = \frac{1}{2}$.
E4-Ruang hampa udara (vakum) di antara dua dinding kaca menghilangkan medium partikel zat sehingga perpindahan kalor konduksi dan konveksi tidak dapat merambat keluar. Tutup isolator dari bahan plastik atau gabus mencegah konveksi udara panas ke lingkungan luar. Lapisan mengilap pada dinding kaca membuat nilai emisivitas permukaan mendekati nol ($e \to 0$) sehingga radiasi gelombang termal dipantulkan kembali ke dalam botol termos.
E5-Satuan tegangan permukaan $\text{N/m} = \frac{\text{kg}\cdot\text{m/s}^2}{\text{m}} = \text{kg}\cdot\text{s}^{-2}$, sehingga dimensinya $[\gamma] = [M][T]^{-2}$. Persamaan frekuensi $[T]^{-1} = ([M][T]^{-2})^p ([M][L]^{-3})^q [L]^r = [M]^{p+q} [L]^{-3q+r} [T]^{-2p}$. Pangkat waktu memberikan $-2p = -1 \Rightarrow p = \frac{1}{2}$. Pangkat massa memberikan $p + q = 0 \Rightarrow q = -p = -\frac{1}{2}$. Pangkat panjang memberikan $-3q + r = 0 \Rightarrow -3\left(-\frac{1}{2}\right) + r = 0 \Rightarrow \frac{3}{2} + r = 0 \Rightarrow r = -\frac{3}{2}$.
